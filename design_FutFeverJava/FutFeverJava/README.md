# FutFever Java

Versão Java Swing do design FutFever originalmente feito em HTML/CSS.

## Como correr

```bash
cd FutFeverJava
javac -d out src/futfever/FutFeverApp.java
java -cp out futfever.FutFeverApp
```

## Conteúdo

- Ecrã inicial com escolha entre utilizador e admin
- Interface mobile para utilizador
- Dashboard admin com sidebar, estatísticas, gráfico e tabelas
- Páginas CRUD genéricas para calendário, jogos, equipas, árbitros, estádios, grupos, bilhetes, utilizadores e relatórios
